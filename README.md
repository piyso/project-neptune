## ⚡ Quickstart (CLI & Local Standalone Web)

### 1. Install & Run via npm
```bash
# Clone the repository
git clone https://github.com/piyso/project-neptune.git
cd project-neptune

# Install dependencies
npm install

# Build production bundle
npm run build

# Start local sovereign preview server (http://localhost:5173)
npm run preview
```

### 2. Using the Neptune Civic CLI
```bash
# Run CLI directly
npx neptune help

# Compile plain grievance narrative into Section 2(f) certified record queries
npx neptune compile "राशन कार्ड 6 महीने से बंद है, कोटेदार अनाज नहीं दे रहा"

# Query CPIO Behavioral Disposition & Supreme Court estoppel chips
```
